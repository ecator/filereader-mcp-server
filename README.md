# Overview

The MCP Server for search/read Excel, Word, PowerPoint, PDF, Text files.

You must install Office 2016 and later versions to use this MCP server.

# Use

[Download the latest version](https://github.com/ecator/filereader-mcp-server/releases) and extract it to any location.

Then add the following configuration to the MCP servers configuration.

```json
{
  "mcpServers": {
    "filereader": {
      "command": "DRIVER:\\PATH\\TO\\filereader-mcp-server.exe",
      "args": ["path1", "path2", "path3", "..."],
      "env": {
        "LANGUAGE": "zh",
        "TIMEOUT": "60",
        "EXCLUDE": "Tools\\.xlsm|SharePoint|OneDrive"
      }
    }
  }
}
```

Please refer to the following if you are using [Codex](https://github.com/openai/codex/blob/main/docs/config.md#mcp-integration).

> `%USERPROFILE%\.codex\config.toml`

```toml
[mcp_servers.filereader]
command = 'cmd'
args = [
    "/c",
    'DRIVER:\PATH\TO\filereader-mcp-server.exe',
    'path1','path2','path3', '...',
]
env = { SystemRoot = 'C:\Windows', LANGUAGE = 'zh', TIMEOUT = '60', EXCLUDE = 'Tools\.xlsm|SharePoint|OneDrive' }
startup_timeout_sec = 300
tool_timeout_sec = 300
enabled = true
```

> **Note that this is only supported on Windows with Office 2016 (64-bit version) or above installed!**

# Command Line Arguments

The server accepts one or more directory paths as arguments. These define the **allowed scope** for the server.
- **Allowed Directories**: Only files within these directories (and their subdirectories) can be searched or read. Any attempt to access files outside these paths will result in an error.
- **Absolute Paths**: It is highly recommended to use absolute paths to avoid ambiguity.

# Environment Variables

- `LANGUAGE`: Set to `en`, `zh`, or `ja` to specify the primary language for search tokenization. Defaults to `en`.
  - **Attention:** This should be set according to the actual content of the files in the **Allowed Directories**.
- `TIMEOUT`: Set to the timeout in seconds for `search_files` tool. Defaults to `180`.
  - **Note:** If you have a large number of files or very large documents, you may need to increase this value.
- `EXCLUDE`: Set to a regular expression pattern to exclude files from search. Defaults to `""`. 
  - **Note:** The regex is matched against the **full path** of the file (case-insensitive).
  - Example: `"Tools\\.xlsm|SharePoint|OneDrive"`.
    - This will match "Tools.xlsm", "SharePoint", and "OneDrive" anywhere in the full path.

# Cache

To improve performance, the server caches the content of files it reads.
- **Mechanism**: When a file is accessed, the server checks its last modified time. If the file hasn't changed since it was last cached, the server will read the content directly from the cache. This significantly speeds up subsequent searches and reads, especially for large Office documents and PDFs.
- **Cache Path**: `%USERPROFILE%\.filereader-mcp-server\.cache`
- **Management**: You can safely delete this folder at any time to clear the cache. The server will automatically rebuild it as files are accessed.
